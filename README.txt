FAMILY TEA PLANNER — FREE CHATGPT VERSION

This is a static web app/PWA. It does not call an API and does not require an API key.
When you tap "Create my AI meal plan in ChatGPT", it opens ChatGPT with a prompt built from your preferences. You send the prompt in ChatGPT. The app cannot automatically pull ChatGPT's answer back into itself; copy the plan or shopping list from ChatGPT and paste it into the save box.

To publish free:
1. Create/sign in to a GitHub account.
2. Create a new PUBLIC repository named family-tea-planner.
3. Upload all files in this folder to the repository root (not the enclosing ZIP).
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; branch main, folder /(root); Save.
6. Wait for GitHub Pages to publish. Open the provided https://...github.io/family-tea-planner/ address in Safari.
7. In Safari tap Share > Add to Home Screen.

The app saves pasted plans in the browser storage on that iPhone. It is not a native App Store app. GitHub Pages is free for a public repository; availability and interface may change.
